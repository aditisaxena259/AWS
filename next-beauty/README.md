# Next Beauty — demo

A tiny Next.js demo that asks a quick question after choosing a category and returns product recommendations.

Getting started

1. cd next-beauty
2. npm install
3. npm run dev

Open http://localhost:3000

Notes
- This is intentionally minimal. Replace sample data in `components/QuestionFlow.tsx` with real data or wire to an API.
- Built with Next 14 and TypeScript.
